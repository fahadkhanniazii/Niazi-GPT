Niazi GPT

A personal AI assistant built with Python and Streamlit.

Niazi GPT is designed as a simple, modern AI assistant interface with support for chat, PDF documents, and image uploads.

Features
💬 AI chat interface
📄 PDF upload support
🖼️ Image upload support
💻 Coding assistance interface
🔄 New chat functionality
📱 Responsive layout
🌙 Dark-themed UI
⚡ Built with Streamlit

Run Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/niazi-gpt.git
cd niazi-gpt

Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

The application will open in your browser.
